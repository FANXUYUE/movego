## 开发原则

- 每个 task 尽量可独立开发、独立验收。
- 第一版采用 React + Vite + Tailwind + shadcn/ui + localStorage。
- 不做真实登录、真实后端、真实好友、视频上传、支付、推送和健康数据接入。
- 以移动端 390px 宽度为主，桌面仅做居中手机壳预览或响应式兼容。

## 推荐开发顺序

1. T001 到 T015：先把工程、壳层、静态数据、localStorage 和全局状态打稳。
2. T016 到 T033：优先完成冒险、快练、任务详情和任务完成闭环。
3. T034 到 T048：接入 Quest、League、社区、我的页的同步展示。
4. T049 到 T057：补 AI 感、演示工具、移动端 QA 和文档。

## MVP 验收标准

- 用户能在手机尺寸下完成至少 1 个主线关卡和 1 个快练。
- 完成任务后 XP、streak、Quest、League、徽章、社区动态、我的页数据同步更新。
- 刷新页面后核心状态保留。
- 5 个底部 Tab 和头像入口都可访问。
- 不依赖真实后端、真实登录、真实好友或真实视频上传即可完整演示产品闭环。
