# 动动 Mascot Assets

动动是一只运动小水豚：戴运动发带、背小水壶、穿运动鞋。性格是松弛、温和、陪伴型，不鸡血、不 PUA。

口头禅：今天不用很猛，动一下就算赢。

## 设计方向

- 形象关键词：圆润、稳定、陪伴、轻运动、校园感、3D 玩具感。
- 主色：草绿色 `#4FBE69` / 深绿 `#167253`，搭配奶白、暖棕和少量运动黄。
- 固定识别元素：绿色运动发带、绿色背心、白色 `D` 标、斜挎小水壶、白绿运动鞋。
- 造型比例：头身比偏可爱，身体圆润稳定，四肢短胖，动作幅度轻松不夸张。
- 表情：温和、放松、像朋友，不做夸张鸡血鼓励。
- 使用语气：鼓励用户“先动一下”，避免压力感、监督感和羞耻感。

## 文件

- `dongdong-action-sheet.png`：新版 3D 动动动作设定表，包含 8 个基础动作。
- `dongdong-3d-avatar.png`：头像 / 顶部入口 / 徽章底图。
- `dongdong-3d-base.png`：默认站立，适合首页用户状态卡。
- `dongdong-3d-cheer.png`：完成任务后的轻鼓励。
- `dongdong-3d-walk.png`：冒险、散步、校园步行任务。
- `dongdong-3d-jog.png`：轻慢跑、心肺入门任务。
- `dongdong-3d-stretch.png`：站姿拉伸、热身提示。
- `dongdong-3d-toe-touch.png`：坐姿拉伸、久坐恢复。
- `dongdong-3d-drink.png`：补水、休息、恢复提示。
- `dongdong-3d-rest.png`：躺平休息、睡前舒缓、疲劳保护。
- `dongdong-*.svg`：早期矢量草稿，保留作备用和低保真占位。

## 使用备注

产品页面优先使用新版 `dongdong-3d-*.png`，不再把吉祥物画死在 CSS 里。后续如果需要皮肤、动作或节日限定，应沿用同一比例、服装元素和色板继续扩展。
